# 论文图件（PNG 版）

本目录保存论文数据可视化与结果展示图的 PNG 版本，用于 GitHub 预览、论文排版和协作审阅。

- 原始生成目录：`outputs/figures/`（默认被 `.gitignore` 忽略）
- 生成脚本：`src/25_export_result_figures.py`、`src/06_robustness.py`、`src/27_export_heterogeneity_groups.py`、`src/34_export_paper_support_materials.py`
- 若需 PDF/JPG 或重新生成图件，请运行 README 中的表图导出命令。
