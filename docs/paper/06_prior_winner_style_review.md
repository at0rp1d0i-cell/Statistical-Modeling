## 1. 总体观察

第十届获奖文选的论文风格大体不是“单一模型展示”，而是“国家战略场景 + 数据工程 + 统计/机器学习方法 + 对比验证 + 可落地建议”的组合。多数文章会在摘要和引言中快速交代现实问题、数据来源、方法链条、对比实验和应用价值；正文则通过图表、技术路线图、模型对比或消融实验增强可信度。

对我们当前论文而言，最适合借鉴的是“稳健实证 + 方法创新型”写法：主线保持数字普惠金融影响碳排放强度的 DML 因果证据，辅线用因果森林异质性和政策文本机制框架体现建模创新，但不把尚未验证的 LLM 评分写成正式机制结论。

## 2. 可直接借鉴的格式特点

### 2.1 摘要写法：背景—数据—方法—实验—贡献

获奖文选中的机器学习/预测类论文通常在摘要中按以下顺序展开：

1. 战略或现实背景；
2. 数据来源与样本范围；
3. 核心方法与模型链条；
4. 关键实验或对比结果；
5. 应用价值、政策意义或方法贡献。

我们当前摘要已经具备这些要素，但可进一步压缩技术细节，把表述改得更像竞赛论文摘要：先点出“双碳 + 数字普惠金融”的战略问题，再报告 2019—2023 年地级市面板和 DML 结果，最后说明异质性、稳健性和政策文本模块的边界。

### 2.2 结构写法：先给研究思路/技术路线图

多篇优秀论文在方法展开前会用“研究思路”“框架结构”“技术路线图”帮助评委迅速理解模型链路。我们的论文目前文字链条完整，但缺一张总览图。已新增可复现图件：

- `outputs/figures/figure_10_research_framework.pdf/png/jpg`
- 生成脚本：`src/34_export_paper_support_materials.py`

建议将该图放在引言末尾或研究方法开头，作用是让评委一眼看到：数据整合 → DML 主识别 → 稳健性/对比 → 异质性 → 政策文本模块。该图只概括既有研究设计，不新增实证结果。

### 2.3 实验写法：明确“对比实验”和“消融/敏感性”

获奖文选中常见两类验证：

- **模型对比实验**：用传统模型、基准模型或单一模型对照主模型，证明主方法不是孤立有效；
- **消融实验**：逐步增加或移除模型模块，说明每个改进模块贡献。

我们的论文当前已有“对比实验/稳健性”证据：DML 与 OLS TWFE 对照、结果变量替换、安慰剂检验、学习器替换、人口变量敏感性。但严格意义上的“消融实验”还没有系统化。若后续用户确认，可以新增一张“控制集规格递进/类消融表”（如无控制、GDP、GDP+产业结构、主规格、主规格+人口），但这属于稳健性策略扩展，需要研究设计确认后再做。

### 2.4 结果写法：结论数字化，边界同步披露

优秀论文通常会把核心结果写成“指标—变化幅度—对比对象—实际含义”。我们的主结果也应采用这种方式：

- 主规格 DML ATE = -0.0540，95% CI [-0.0951, -0.0130]，p = 0.0099；
- 安慰剂检验真实 ATE 位于置换分布尾部，经验 p = 0.0040；
- 人口敏感性加入后 ATE 收缩且不显著，必须作为边界披露。

这样既有结果强度，也不会过度宣称因果识别。

### 2.5 政策文本写法：放在方法创新/机制展望，避免过度声称

文选中的政策文本类文章通常会把文本挖掘、主题模型、词频/词云或政策评价与指标体系结合，作为解释现实问题的辅助证据。我们的 LLM 政策文本模块可以借鉴这种“文本结构化—机制解释”的写法，但当前状态是 `not_ready`，因此建议：

- 正文中写“本文构建政策文本机制分析链路”；
- 技术附录展示 policy seed、规则代理评分和 LLM readiness gate；
- 不写“LLM 已验证数字绿色协同机制显著成立”。

## 3. 对当前论文的具体改稿建议

### 3.1 题目和定位

当前题目“‘双碳’战略下数字普惠金融的碳减排效应：基于中国地级市面板的双重机器学习因果推断与政策文本机制分析”符合获奖论文常见的“现实问题 + 方法副标题”结构，暂不建议再改。

### 3.2 正文结构建议

建议最终稿采用以下结构：

1. 摘要、关键词；
2. 引言：战略背景、研究问题、识别难点、边际贡献；
3. 文献综述与理论机制；
4. 数据来源、变量定义与样本构造；
5. 研究方法与识别策略；
6. 基准结果；
7. 稳健性与对比实验；
8. 异质性分析；
9. 政策文本机制框架与技术附录说明；
10. 结论、政策建议与局限性。

其中第 7 节可以在标题中显式使用“对比实验”，以贴近获奖论文常见表达；第 9 节要明确“方法框架”而非“已完成机制检验”。
